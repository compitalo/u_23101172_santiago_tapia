# Evidencia 05 — Análisis de una finalidad secundaria (marketing)

## Objetivo
Evaluar si la organización puede reutilizar los datos de clientes para "enviar promociones
personalizadas basadas en edad, ciudad y comportamiento de compra".

## Procedimiento
1. Se identificó la finalidad original de cada dato (ver evidencia 01).
2. Se contrastó la nueva finalidad contra el principio de limitación de finalidad.
3. Se determinó qué datos serían estrictamente necesarios.
4. Se propusieron controles técnicos y administrativos.

## 1. ¿El hecho de que la organización ya tenga los datos significa automáticamente que puede utilizarlos para cualquier finalidad?

No ya que hacer eso seria una infracicon grave contra las normativas de proteccion de datos personales como indica en la ley LFPDPPP

## 2. ¿Qué preguntas debería realizar la organización antes de implementar este tratamiento?

¿cuanto tiempo se conservaran los perfiles y los datos?

Al realizar este tratamiento¿se adquirio el consentimiento de los usuarios para este fin?

En el aviso de privacidad¿se contemplo el uso para el marketing?

## 3. ¿Qué datos serían realmente necesarios?

Dependiendo el tipo de uso que se le vaya a dar, por ejemplo si es con finalidad de marketing

solo es necesario un seudonimo del cliente, no es necesario el nombre ni el rfc algun canal por el cual mandarle publicidad como puede ser el correo electronico, datos con los cuales hacer segmento como puede ser la edad y la region y talvez un historial de compras de usuario para saber cuales son los productos populares no es necesaria mucha informacion especifica en esta parte.

## 4. ¿Necesitaría el área de marketing acceso directo a *clientes*?

El area de marketing no necesita acceso directo solo necesita una vista segmentada de los datos

## 5. ¿Qué controles técnicos podrían limitar la información entregada?

Vista de segmentos, rol para el area de marketing con acceso limitado si es necesario, seudonimiazacion, anonimato minimo, etc
